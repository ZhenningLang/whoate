# whoate

**Who ate my RAM?** A macOS tool that tells you *whose* process is eating memory and CPU — the tmux pane, the coding-agent session, the app, or the orphan left behind by a closed terminal — not just a process name.

- **GUI** (SwiftUI) for people: owners ranked by memory/CPU, plain-language verdicts, evidence for every attribution.
- **CLI** for coding agents and scripts: one command, structured JSON, meaningful exit codes, zero tokens.

> Status: under active development. Design notes live in [`docs/design.md`](docs/design.md).
